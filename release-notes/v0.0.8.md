## S3MANAGER v0.0.8

DigitalOcean Spaces için masaüstü dosya yöneticisi — ayarlar merkezi, tema iyileştirmeleri ve S3 API genişletmesi.

### Yeni

- **Ayarlar menüsü** — Bağlantı, Yükleme Metadata, Görünüm, Günlük, **Bakım**, Yardım sekmeleri
- **Nesne özellikleri** — Mevcut dosyada Content-Type, Cache-Control, özel metadata ve ACL (private/public-read)
- **Bakım** — Yarım multipart yüklemeleri listele / iptal et
- **Bağlantı göstergesi** — Toolbar'da yeşil/kırmızı durum noktası
- **Light/Dark tutarlılık** — Dialoglar, önizleme, tablolar ve read-only alanlar paletle uyumlu
- **macOS çift DMG** — Apple Silicon (arm64, macOS 13+) ve Intel Mac (x86_64, macOS 10.13+); günlük geliştirme PySide6 ile devam eder

### İyileştirmeler

- Toolbar iki satır (breadcrumb + genişleyen arama)
- Toplu silme `delete_objects` batch ile hızlandırıldı
- Transferler başlığı ve Bakım tablosu light modda düzeltildi

### Teknik

- Yeni: `settings_dialog.py`, `object_properties_dialog.py`, `incomplete_uploads_panel.py`, `upload_metadata_panel.py`, `log_viewer.py`
- `SpacesClient`: ACL/metadata güncelleme, batch delete, multipart yönetimi
- macOS Intel release: `build/macos_x86_64/` PySide6→PySide2 shim, `s3manager-macos-x86_64.spec`, **python-build-standalone** 3.10.15 (macOS 10.13 `libpython` uyumluluğu)
- 93 otomatik test (pytest + moto)
