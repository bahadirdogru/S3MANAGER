## S3MANAGER v1.0.0 — Tauri ile yeniden yazıldı

S3MANAGER artık **Tauri 2** ile geliştiriliyor: Rust backend + SvelteKit/TypeScript arayüz (shadcn-svelte). Daha küçük kurulum, daha hızlı açılış, native performans.

### Yenilikler
- DigitalOcean Spaces'in yanında **her S3 uyumlu servis** (AWS S3, MinIO, Cloudflare R2…): özel endpoint, bölge ve path-style adresleme
- 16 MB üzeri dosyalarda parçalı yükleme ve parça bazlı ilerleme; iptal edilen yüklemeler sunucuda yarım parça bırakmaz
- Kopyalama, taşıma ve metadata düzenleme dosyanın erişim ayarını (public/private) korur
- Herkese açık dosyalarda açık URL gösterimi ve kopyalama
- İndirmeler `.part` dosyasına yazılır, tamamlanınca yeniden adlandırılır
- Yenilenen arayüz: önizleme paneli, transfer paneli, bildirimler, kısayollar

### Uyumluluk
- Ayarlar `~/.s3manager/config.ini` dosyasından okunur; mevcut kurulumlar olduğu gibi çalışır
- Minimum macOS 10.15 Catalina

### İndirme
| Platform | Dosya |
|----------|-------|
| Windows | `*_x64-setup.exe` veya `*_x64_tr-TR.msi` |
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Linux | `*.AppImage`, `*.deb`, `*.rpm` |

> Binary'ler kod imzalı değildir; Windows SmartScreen / macOS Gatekeeper uyarı verebilir.
