## S3MANAGER v0.0.9

Intel macOS DMG'sindeki PySide2/PySide6 çakışması düzeltmesi.

### Düzeltmeler

- **Intel macOS (x86_64) açılış hatası** — `RuntimeError: Cannot execute run-time hook for 'PySide6' because run-time hook for 'PySide2' has been run before` giderildi
- Legacy build artık `requirements-dev.txt` kurmaz (PySide6 wheel'i venv'e girmiyordu)
- Build sonrası `verify-macos-x86_64-bundle.sh` ile gerçek PySide6/Qt6 binary'lerinin paketlenmediği doğrulanır

### Kurulum

| Platform | Dosya | Min. macOS |
|----------|-------|------------|
| Windows | `S3MANAGER-0.0.9-windows-setup.exe` veya portable zip | — |
| macOS (Apple Silicon) | `S3MANAGER-0.0.9-macos-arm64.dmg` | 13 Ventura+ |
| macOS (Intel) | `S3MANAGER-0.0.9-macos-x86_64.dmg` | 10.13 High Sierra+ |
| Linux x86_64 | `tar.gz` veya `AppImage` | — |

Intel Mac kullanıcıları: v0.0.8 `*-macos-x86_64.dmg` yerine bu sürümü indirin.
